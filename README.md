## Was hier liegt

```
/docs        — Schema, Styleguide, Architektur-Entscheidungen
/content     — Die Texte selbst (Markdown, mehrsprachig)
/public      — Statische Dateien (später)
/scripts     — Hilfsskripte für Migration aus alten Quellen
```

zuerst erprobt, bevor das Frontend gebaut wird.
